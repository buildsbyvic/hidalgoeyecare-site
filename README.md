# Hidalgo Eye Care & Optical

Source for [hidalgoeyecare.com](https://hidalgoeyecare.com), the website of Hidalgo Eye Care & Optical, a family eye care practice and optical in Tampa, Florida.

The site is plain HTML, CSS and JavaScript with no framework, hosted on GitHub Pages. It is bilingual: English pages live at their usual addresses and Spanish pages under `/es/` (for example `/services/` and `/es/services/`), linked with `hreflang` tags. The English/Español button switches between the matching pages and remembers the choice.

## Layout

```
_src/pages/      Page content (home, services, eyewear, insurance, about, contact, privacy, 404)
_src/partials/   Shared header and footer
_src/build.py    Stamps the header and footer onto each page and writes the published files
_src/check.py    Pre-publish checks
assets/          Stylesheet, script, images and documents
```

The page folders at the top level (`services/`, `contact-us/` and so on), the Spanish copies in `es/`, `index.html`, `404.html`, `sitemap.xml` and `CNAME` are generated by the build. Edit the files in `_src/`, not the generated ones. Each source page holds both languages; the build writes an English-only and a Spanish-only copy of it.

A few top-level folders (`why-us/`, `gallery/` and others) are small redirect pages that send old addresses from the previous site to the right page.

## Updating the site

Requires Python 3.10 or newer.

1. Edit the page in `_src/pages/`, or the shared header and footer in `_src/partials/`. Add both the English (`class="en"`) and Spanish (`class="es" lang="es"`) text.
2. Build: `python _src/build.py`
3. Check: `python _src/check.py` (links, image sizes and alt text, page titles and descriptions)
4. Preview: `python -m http.server 8000`, then open http://localhost:8000
5. Commit and push to `main`. GitHub Pages publishes the change within a few minutes.
